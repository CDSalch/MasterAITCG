The code is easily adaptable to another TCG with the help of recorder.py, opening a chroome driver and recording the button clicked. 
\\ \\
browser_driver.py - Chrome process launcher and Playwright helper utilities. \\
config.py - Configuration constants, selectors, and CLI argument parser. \\
database.py - Collection scraping and incremental database updating for cards_db.json. \\
deck_builder.py - Deck optimization algorithm (Monte Carlo) and Deck Lab automation.\\
deck_lab.py - Automatic construction of the deck\\
game_engine.py - Game logics\\
main.py - Entry point\\
seat_report.py - Provides Wilson intervals \\
